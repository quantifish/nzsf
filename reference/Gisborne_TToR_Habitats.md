# Gisborne Te Tapuwae o Rongokako Habitats

Gisborne Te Tapuwae o Rongokako Habitats provided by the Department of
Conservation (DOC).

## Usage

``` r
Gisborne_TToR_Habitats
```

## Format

Simple feature collection with 482 features and 15 fields:

- DEPTH:

  the depth (m) of the habitat

- SUBSTRATE:

  the type of subsrate

- Habitat:

  the type of habitat

- TYPE:

  the type of habitat
