# Plot CRA labels

Plot CRA labels

## Usage

``` r
geom_cra(feature = "label", proj = proj_nzsf(), qma = NULL, area = NULL, ...)
```

## Arguments

- feature:

  a spatial feature data.

- proj:

  The projection to use.

- qma:

  a spatial feature data.

- area:

  the field to rasterize.

- ...:

  the field to rasterize.

## Value

a `ggplot2` geom.
