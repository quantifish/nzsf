# New Zealand protected areas and marine habitats

Snapshot protected-area and habitat layers used for contextual mapping.

## Usage

``` r
doc_marine_reserves

Hauraki_Gulf_Marine_Park

Gisborne_TToR_Habitats

Gisborne_TToR_Reefs

Rocky_reef_National_NZ
```

## Format

Simple-feature objects: \`doc_marine_reserves\` has 50 features and one
attribute; \`Hauraki_Gulf_Marine_Park\` has one feature and 19
attributes; \`Gisborne_TToR_Habitats\` has 482 features and 15
attributes; \`Gisborne_TToR_Reefs\` has three features and one
attribute; and \`Rocky_reef_National_NZ\` has 4,817 features and one
attribute.

An object of class `sf` (inherits from `data.frame`) with 50 rows and 2
columns.

An object of class `sf` (inherits from `data.frame`) with 1 rows and 20
columns.

An object of class `sf` (inherits from `data.frame`) with 482 rows and
16 columns.

An object of class `sf` (inherits from `data.frame`) with 3 rows and 2
columns.

An object of class `sf` (inherits from `data.frame`) with 4817 rows and
2 columns.
