# New Zealand hoki QMAs

New Zealand hoki (HOK) Quota Management Areas (QMAs).

## Usage

``` r
HOKI_QMA
```

## Format

Simple feature collection with 2 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
