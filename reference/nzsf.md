# New Zealand Spatial Features

The nzsf package provides two main categories of important functions:
`get` and `plot`. Several other helper functions are also available,
such as the `proj` functions which can be used to easily specify a
useful projection to use.

## Get functions

The get functions retrieve bundled spatial data and perform requested
processing, such as transformation to a different projection. These
functions return simple-feature or raster objects.

## Plot functions

The plot functions combine a get function with an appropriate `ggplot2`
geom.
