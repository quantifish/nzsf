# New Zealand Inshore Statistical Areas

A more detailed summary for the New Zealand inshore Statistical Areas
can be found at
<https://data-mpi.opendata.arcgis.com/datasets/general-statistical-areas>.

## Usage

``` r
nz_inshore_statistical_areas
```

## Format

Simple feature collection with 53 features and 3 fields:

- OBJECTID:

  the object ID

- Statistica:

  the statistical area

- Statisti_2:

  the statistical area

## Source

Fisheries New Zealand
<https://data-mpi.opendata.arcgis.com/datasets/general-statistical-areas>
