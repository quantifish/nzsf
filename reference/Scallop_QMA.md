# New Zealand scallop QMAs

New Zealand scallop (SCA) Quota Management Areas (QMAs).

## Usage

``` r
Scallop_QMA
```

## Format

Simple feature collection with 13 features and 5 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name

- QmaName:

  Quota Management Area or stock name
