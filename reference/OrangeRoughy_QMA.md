# New Zealand orange roughy QMAs

New Zealand orange roughy (ORH) Quota Management Areas (QMAs).

## Usage

``` r
OrangeRoughy_QMA
```

## Format

Simple feature collection with 4 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
