# CCAMLR geometries

CCAMLR geometries

## Usage

``` r
geom_ccamlr(
  feature = "ssru",
  proj = proj_ccamlr(),
  fill = NA,
  colour = "black",
  ...
)
```

## Arguments

- feature:

  A Quota Managemetn Area (QMA). Can be EEZ, CRA, JMA.

- proj:

  The projection to use.

- fill:

  The projection to use.

- colour:

  The projection to use.

- ...:

  The projection to use.

## Value

New Zealands statistical areas as a `sf` object.
