# New Zealand paua QMAs

New Zealand paua (PAU) Quota Management Areas (QMAs).

## Usage

``` r
Paua_QMA
```

## Format

Simple feature collection with 11 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name

- QmaName:

  Quota Management Area or stock name
