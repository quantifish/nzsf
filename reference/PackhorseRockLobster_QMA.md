# New Zealand packhorse rock lobster QMAs

New Zealand packhorse rock lobster Quota Management Areas (QMAs).

## Usage

``` r
PackhorseRockLobster_QMA
```

## Format

Simple feature collection with 1 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name

## Source

Fisheries New Zealand
