# New Zealand oreo QMAs

New Zealand oreo (OEO) Quota Management Areas (QMAs).

## Usage

``` r
OREO_QMA
```

## Format

Simple feature collection with 5 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
