# CCAMLR coord

CCAMLR coord

## Usage

``` r
coord_ccamlr(proj = proj_ccamlr(), ...)
```

## Arguments

- proj:

  The projection to use.

- ...:

  Other arguments passed to
  [`ggplot2::geom_sf()`](https://ggplot2.tidyverse.org/reference/ggsf.html).

## Value

A CCAMLR `ggplot2` layer.
