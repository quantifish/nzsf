# New Zealand jack mackerel QMAs

New Zealand jack mackerel (JMA) Quota Management Areas (QMAs).

## Usage

``` r
JackMackerel_QMA
```

## Format

Simple feature collection with 4 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
