# New Zealand ling QMAs

New Zealand ling (LIN) Quota Management Areas (QMAs).

## Usage

``` r
LING_QMA
```

## Format

Simple feature collection with 8 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
