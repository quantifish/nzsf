# Hauraki Gulf Marine Park

Hauraki_Gulf_Marine_Park.

## Usage

``` r
Hauraki_Gulf_Marine_Park
```

## Format

Simple feature collection with 1 feature and 19 field:

- OBJECTID:

  name of the marine reserve

- NaPALIS_ID:

  name of the marine reserve

- Start_Date:

  name of the marine reserve

- End_Date:

  name of the marine reserve

- Type:

  name of the marine reserve

- Name:

  name of the marine reserve

- Legislatio:

  name of the marine reserve

- Section:

  name of the marine reserve

- Local_Purp:

  name of the marine reserve
