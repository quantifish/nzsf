# New Zealand red rock lobster QMAs

New Zealand red rock lobster (Jasus edwardsii) Quota Management Areas
(QMAs).

## Usage

``` r
SpinyRedRockLobster_QMA
```

## Format

Simple feature collection with 10 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name

Fisheries New Zealand
