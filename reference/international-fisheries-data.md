# International fisheries areas

Snapshot statistical, management, and convention-area boundaries for
international fisheries organisations.

## Usage

``` r
SPRFMO

SIOFA

CCSBT

ccamlr_eez

ccamlr_mpa

ccamlr_ssru

ccamlr_statistical_areas
```

## Format

Simple-feature objects: \`SPRFMO\` (8 features, 3 attributes), \`SIOFA\`
(9, 29), \`CCSBT\` (12, 2), \`ccamlr_eez\` (7, 13), \`ccamlr_mpa\` (6,
12), \`ccamlr_ssru\` (63, 13), and \`ccamlr_statistical_areas\` (19, 6).

An object of class `sf` (inherits from `data.frame`) with 8 rows and 4
columns.

An object of class `sf` (inherits from `data.frame`) with 9 rows and 30
columns.

An object of class `sf` (inherits from `data.frame`) with 12 rows and 3
columns.

An object of class `sf` (inherits from `data.frame`) with 7 rows and 14
columns.

An object of class `sf` (inherits from `data.frame`) with 6 rows and 13
columns.

An object of class `sf` (inherits from `data.frame`) with 63 rows and 14
columns.

An object of class `sf` (inherits from `data.frame`) with 19 rows and 7
columns.

## Source

SPRFMO, SIOFA, CCSBT, and CCAMLR; CCAMLR spatial data are available from
<https://spatial.ccamlr.org/>.
