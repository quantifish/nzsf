# New Zealand scampi QMAs

New Zealand scampi Quota Management Areas (QMAs).

## Usage

``` r
Scampi_QMA
```

## Format

Simple feature collection with 1 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
