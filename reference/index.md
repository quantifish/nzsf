## Helpers

- [`get_coast()`](https://www.quantifish.co.nz/nzsf/reference/get_coast.md)
  : Get the New Zealand coastline
- [`get_conditional_smooths()`](https://www.quantifish.co.nz/nzsf/reference/get_conditional_smooths.md)
  : Plot a conditional_smooths output
- [`get_depth()`](https://www.quantifish.co.nz/nzsf/reference/get_depth.md)
  : Get depth polylines around New Zealand
- [`get_marine_reserves()`](https://www.quantifish.co.nz/nzsf/reference/get_marine_reserves.md)
  : Get Marine Reserves
- [`get_points_as_raster()`](https://www.quantifish.co.nz/nzsf/reference/get_points_as_raster.md)
  : Convert points to a raster
- [`get_qma()`](https://www.quantifish.co.nz/nzsf/reference/get_qma.md)
  : Get Quota Management Area (QMA) polygons
- [`get_standard_grid()`](https://www.quantifish.co.nz/nzsf/reference/get_standard_grid.md)
  : Get Fisheries New Zealand standard grid definitions
- [`get_standard_grid_origin()`](https://www.quantifish.co.nz/nzsf/reference/get_standard_grid_origin.md)
  : Get Fisheries New Zealand standard grid origin
- [`get_statistical_areas()`](https://www.quantifish.co.nz/nzsf/reference/get_statistical_areas.md)
  : Get Statistical Areas
- [`lookup_depth()`](https://www.quantifish.co.nz/nzsf/reference/lookup_depth.md)
  : Look up GEBCO elevation at specific locations around New Zealand
