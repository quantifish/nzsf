# New Zealand pipi QMAs

New Zealand pipi (PIP) Quota Management Areas (QMAs).

## Usage

``` r
Pipi_QMA
```

## Format

Simple feature collection with 10 features and 5 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name

- QmaName:

  Quota Management Area or stock name
