# New Zealand silver warehou QMAs

New Zealand silver warehou (SWA) Quota Management Areas (QMAs).

## Usage

``` r
SilverWarehou_QMA
```

## Format

Simple feature collection with 4 features and 4 fields:

- QMA:

  Quota Management Area or stock

- SpeciesCode:

  Species code

- SpeciesScientific:

  Scientific name

- SpeciesCommon:

  Common name
