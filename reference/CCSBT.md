# CCSBT Management Areas

The Commission for the Conservation of Southern Bluefin Tuna (CCSBT)
Management Areas data set is a `sf` shapefile.

## Usage

``` r
CCSBT
```

## Format

Simple feature collection with 12 features and 2 fields:

- id:

  The CCSBT Management Area

- Area:

  The CCSBT Management Area

## Source

The CCSBT Data Manager (<datamanager@ccsbt.org>).
